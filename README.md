# Автоматическое создание анкет в Яндекс.Формах

Скрипт на Python, который помогает быстро создать и заполнить анкету в админ-панели Яндекс.Форм. Вы один раз описываете структуру опроса в текстовом файле, а программа сама создает форму и переносит в нее все вопросы, варианты ответов и настройки.

## Возможности

- Создание новой формы с нуля.
- Разбивка опроса на страницы (`[PAGE]`) и добавление текстовых блоков (`[SECTION]`).
- Поддержка всех популярных типов вопросов:
  - Короткий текст (`[T]`)
  - Длинный текст (`[L]`)
  - Один вариант (`[R]`)
  - Несколько вариантов (`[M]`)
  - Выпадающий список (`[DD]`)
  - Матрица / Оценка по шкале (`[S]`)
- Управление обязательностью вопросов (`[OPT]`).
- Добавление пояснений к вопросам (`[D]`).
- Настройка отображения шкал (`[W]`).

## Что понадобится

- Python 3.9 или выше.
- Аккаунт Яндекс, у которого есть доступ к созданию форм.
- Браузер Google Chrome или Chromium (Playwright скачает его автоматически).

## Начало работы

### 1. Установка

Скачайте проект и установите все необходимые библиотеки.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/rem94-png/yandex_forms_automatic.git
cd yandex_forms_automatic

# 2. Создайте и активируйте виртуальное окружение (рекомендуется)
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate

# 3. Установите зависимости
pip install -r requirements.txt

# 4. Установите браузер для работы скрипта
playwright install chromium
2. Настройка
Скопируйте файл с примером настроек и при необходимости отредактируйте его:

bash
cp .env.example .env
В файле .env можно указать свои пути к файлам, но обычно это не требуется — всё работает из коробки.

3. Подготовка вопросов
Создайте в папке с проектом файл questions.txt. В нем вы описываете структуру вашей анкеты с помощью простых маркеров.

Пример:

text
[PAGE]
Моя первая страница

[Q]
[R]
[D] Выберите один из вариантов
Какой вариант вам подходит?
[A]
Вариант 1
Вариант 2
Вариант 3
Основные маркеры:

[PAGE] — Новая страница. Заголовок пишется на следующей строке.

[SECTION] — Текстовый блок без вопроса.

[Q] — Начало нового вопроса.

[T], [L], [R], [M], [S], [DD] — Тип вопроса.

[OPT] — Делает вопрос необязательным.

[D] — Текст пояснения к вопросу.

[A] — Начало списка вариантов ответа.

[C] — Начало списка критериев (для матриц).

Более подробный пример смотрите в файле questions.example.txt.

4. Запуск
Убедитесь, что вы находитесь в папке с проектом и виртуальное окружение активировано.

Выполните команду:

bash
python create_form.py
Откроется окно браузера. Войдите в свой Яндекс-аккаунт.

Когда увидите главную страницу админки Яндекс.Форм (список форм), вернитесь в консоль и нажмите Enter.

Скрипт начнет автоматически создавать форму и заполнять ее вопросами из вашего файла.

Если что-то пошло не так
Скрипт не находит элементы на странице. Убедитесь, что вы вошли в аккаунт и находитесь именно на странице со списком форм.

Ошибка при установке браузера. Попробуйте выполнить команду playwright install chromium еще раз.

Скрипт остановился с ошибкой. В папке с проектом появится скриншот экрана (файл error_*.png). По нему можно понять, на каком шаге что-то пошло не так. Также проверьте, что файл questions.txt заполнен по правилам, описанным выше.
