# Автоматическое создание анкет в Яндекс.Формах

Скрипт на Python (Playwright) для автоматического создания и заполнения форм в админ-панели Яндекс.Форм на основе текстового файла с вопросами.

## Возможности

- Создание формы с нуля.
- Поддержка разбивки на страницы (`[PAGE]`) и текстовые блоки/секции (`[SECTION]`).
- Поддержка различных типов вопросов:
  - Короткий текст (`[T]`)
  - Длинный текст (`[L]`)
  - Один вариант (`[R]`)
  - Несколько вариантов (`[M]`)
  - Выпадающий список (`[DD]`)
  - Матрица / Оценка по шкале (`[S]`)
- Настройка обязательности вопросов (`[OPT]`).
- Добавление пояснений к вопросам (`[D]`).
- Настройка виджетов для шкал (`[W]`).

## Требования

- Python 3.9 или выше.
- Установленный браузер Google Chrome или Chromium (Playwright скачает свой).
- Аккаунт Яндекс, имеющий доступ к созданию форм.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/rem94-png/yandex_forms_automatic.git
   cd yandex_forms_automatic
Создайте и активируйте виртуальное окружение (рекомендуется):

bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для macOS/Linux:
source venv/bin/activate
Установите зависимости:

bash
pip install -r requirements.txt
Установите браузер для Playwright:

bash
playwright install chromium
Настройка
Переменные окружения
Скопируйте файл .env.example в .env:

bash
cp .env.example .env
При необходимости отредактируйте .env. Скрипт использует следующие переменные (если они не заданы, используются значения по умолчанию):

QUESTIONS_FILE — путь к файлу с вопросами (по умолчанию questions.txt).

YANDEX_PROFILE_DIR — папка для сохранения профиля браузера (по умолчанию ./yandex_profile). В ней сохраняются cookies, чтобы не авторизовываться каждый раз заново. Не добавляйте эту папку в Git.

Файл с вопросами
Создайте файл questions.txt в корне проекта (или переименуйте questions.example.txt). В нем описывается структура вашей анкеты.

Синтаксис файла:

[PAGE] — Начинает новую страницу. На следующей строке указывается заголовок страницы.

[SECTION] — Создает текстовый блок (без поля для ответа).

[Q] — Начинает новый вопрос.

[T] — Тип: Короткий текст.

[L] — Тип: Длинный текст.

[R] — Тип: Один вариант.

[M] — Тип: Несколько вариантов.

[S] — Тип: Матрица.

[DD] — Тип: Выпадающий список.

[OPT] — Делает вопрос необязательным.

[W] onerow или [W] stars — Настройка отображения шкалы.

[D] — Текст пояснения к вопросу.

[A] — Начало списка вариантов ответа (каждый с новой строки).

[C] — Начало списка критериев (для матриц).

Пример правильного заполнения смотрите в файле questions.example.txt.

Запуск
Убедитесь, что вы находитесь в папке с проектом и виртуальное окружение активировано.

Запустите скрипт:

bash
python create_form.py
Откроется окно браузера. Если вы запускаете скрипт впервые, вам потребуется войти в свой Яндекс-аккаунт вручную.

После того как вы войдете и увидите главную страницу админки Яндекс.Форм (список форм), вернитесь в консоль и нажмите Enter.

Скрипт автоматически создаст новую форму и начнет заполнять её вопросами из файла.
