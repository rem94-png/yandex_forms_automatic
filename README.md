# Yandex Forms Automation

Скрипт для автоматического создания анкет в Яндекс.Формах.

## Установка

1. Установите Python 3.9+.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
Установите браузер для Playwright:

bash
playwright install chromium
Настройка
Скрипт использует переменные окружения (можно задать в файле .env или в системе):

QUESTIONS_FILE — путь к файлу с вопросами (по умолчанию questions.txt).

YANDEX_PROFILE_DIR — папка для профиля браузера (по умолчанию ./yandex_profile). В этой папке сохраняются cookies и сессии, чтобы не входить каждый раз заново. Не коммитьте её в Git.

Создайте файл questions.txt по образцу questions.example.txt.

Запуск
bash
python create_form.py
При запуске откроется браузер. Войдите в свой Яндекс-аккаунт, дождитесь загрузки админки форм и нажмите Enter в консоли. Скрипт создаст новую форму и заполнит её вопросами из файла.

Формат файла вопросов
Поддерживаются маркеры:

[PAGE] — новая страница (следующая строка — заголовок).

[SECTION] — текстовый блок без вопроса.

[Q] — начало вопроса.

[T] — короткий текст.

[L] — длинный текст.

[R] — один вариант.

[M] — несколько вариантов.

[S] — матрица (критерии + варианты).

[DD] — выпадающий список.

[OPT] — необязательный вопрос.

[W] onerow или [W] stars — виджет для шкалы.

[D] — описание вопроса.

[A] — начало списка вариантов ответа.

[C] — начало списка критериев (для матрицы).

Примеры смотрите в questions.example.txt
